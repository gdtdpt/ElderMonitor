## 实测踩坑（写进了 dev-guide §8 与 PROJECT §6，将来 mac 首跑用得上）

1. **FFI 上下文指针必须堆分配且地址终身稳定**——两个真实段错误：
   a. resolver 是 create() 的栈局部变量 → 返回后悬空
   b. update callback 的 Box 头部存在 struct 字段里，但 RenderContext 从栈局部 move 进
      Running 后字段地址变了 → mpv 内部线程回调摸旧地址
   修法：双 Box（`Option<Box<UpdateCallback>>` / `Box<ProcResolver>`）
2. glow 构造要读 GL_VERSION，必须放在 make_current 之后，否则 panic
3. glutin 0.32：Surface 与 Context 分离；swap_buffers/resize 在 Surface 上且要传 &ctx
4. winit inner_size() 是物理像素（DPI 缩放，逻辑 960x540 → 物理 1920x1080）
5. wglGetProcAddress 不解析 GL 1.1 核心函数——glutin 已做 opengl32.dll 回退，不用自己处理
