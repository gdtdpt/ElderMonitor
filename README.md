# ElderMonitor（老头监控器）

把多个直播间排在一整块屏幕上同时看，**每一路的音量单独调**：主听的调大、唱歌的调小、
只看画面的静音。

> **当前状态：开发中，还不能用。**
> 目前只有底层（解析 + 播放内核）跑通，还没有界面。M1 做出窗口后才有画面可看。
> 进度见 `PROJECT.md` §5。

## 打算做成什么样

- 一路一格子，格子数跟着「你要看几路」自动排，不需要选 2×2 / 3×3
- 可以指定一路当主格（占大头、居中），其余在四周排开
- 每格底部一条音量滑条 + 静音；音量跟着直播间记，换格子不会丢
- 记录库：加过的直播间都留着，想看的拉到格子里，不想看的收起来，布局自动重排
- 解压即用，不装运行时、不写注册表
- Windows 为主，macOS 一起维护

## 将来的使用方式（发布后按此操作）

1. 解压 zip，双击 `ElderMonitor.exe`
2. 贴一个 B 站房间号或直播间链接（`live.bilibili.com/7734200` 都行）
3. 每格底部调音量，双击某格把它变成主画面

## 已知限制

- **只支持 B 站**（抖音等其他平台不在第一版范围）
- **没有登录**，所以画质上限是 720p（B 站未登录的实际情况）
- 不录制（录制用 [TideWatch](https://github.com/gdtdpt/TideWatch)）
- 不支持 Windows 10 1709 这类老系统（播放内核要求较新的系统）

## 网络要求

多路同时播放会同时占用多份带宽。按 720p 每路约 2~3 Mbps 估算，
9 路大约需要 20~30 Mbps 的稳定下行。
